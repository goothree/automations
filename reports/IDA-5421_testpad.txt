IDA-5421 — Module using bootstrap:
Prerequisites: PRE-01: Build and environment (P1); PRE-02: Test tenants (P1); PRE-03: Browser setup (P1); PRE-04: Modules to test (P1)

TC-01: Top menu Help — Smart Care URL (P1)
	Locate Help in the top menu.
	Click Help.
	Verify URL in browser address bar or new tab.

TC-02: Bottom Help — Smart Care Customer Portal link (P1)
	Open Help from the bottom of the page (Help section).
	Inspect the pop-up / panel link text.
	Click the link.

TC-03: Bottom Help — ticket form removed (P1)
	Open bottom Help section / pop-up.
	Search the panel for ticket submission, incident form, or Zendesk embed form fields.
	Confirm only expected content remains (custom message if set, Smart Care link, any static help text per design).

TC-04: Custom help message — admin configured (P1)
	In admin dashboard, confirm custom help message is configured (note exact text).
	Log in as end user on that tenant; open Help at the bottom of the page.
	Confirm Smart Care link still present and correct (TC-02).

TC-05: Custom config / serviceEndpoints — URL not overridden (P1)
	On affected tenant, click Help in top menu.
	Open bottom Help; click Smart Care Customer Portal link.
	Document tenant ID and config source if URL incorrect (file defect).

TC-06: Module using bootstrap — top and bottom Help parity (P1)
	Repeat TC-01 (top menu Help) in the bootstrap module.
	Repeat TC-02 and TC-03 (bottom Help link + no form).

TC-07: Module using bootstrap — custom help message and config tenant (P2)
	Verify custom help message in module using bootstrap (TC-04).
	Verify Smart Care URL on config/serviceEndpoints tenant (TC-05).

TC-08: Regression — navigation and unrelated Help UX (P2)
	Verify other top-menu items still navigate correctly (no broken routes from Help change).
	Verify login, logout, and primary module functions unaffected.
	Confirm no console errors on Help open/close.

TC-09: End-to-end smoke (P1)
	Top Help → Smart Care URL (TC-01)
	Bottom Help → portal link text + URL (TC-02)
	No ticket form (TC-03)
	Custom message tenant (TC-04) if available
	Config tenant Smart Care URL (TC-05) if available
	TC-06 smoke on each bootstrap module in scope (PRE-04)
