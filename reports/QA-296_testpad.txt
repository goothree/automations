TC-02: R2C — supported delivery types (A2) (P1)

TC-03: R2C — Hardware Buffer mode (A3) (P1)

	Change resolution for each camera.

TC-05: R2C — camera enable / disable (A5) (P1)

	Re-enable top camera.

TC-06: Ambient Monitoring — R2C (B1) (P1)

	Verify alerts behave normally.

TC-07: HSA Application — R2X (B3) (P1)
	Verify application starts normally.
	Verify bottom camera connection succeeds.
	Verify inference / data collection continues.
	Verify VM calls work.
	Verify UI shows normal operation.

TC-08: Application configuration — get-app-config (C1) (P1)
	Publish MQTT command: `{"command":"get-app-config"}`
	Capture response on `adbcresponse` topic.

TC-09: Face blur — R2X (C2) (P1)
	Capture baseline preview without blur.
	Enable: `{"command":"face-blur-on","pixelSize":22}` — validate blur active.
	Send face-blur-on again while already active.
	Disable: `{"command":"face-blur-off"}`.
	Enable blur again after disable.
